1. قبل البدء: طرق التشغيل والحسابات

طرق التشغيل

  • ملف تنفيذي (Windows): شغّل dist\HospitalMS.exe — يشغّل خادمًا محليًا على المنفذ 8765 ويفتح المتصفح تلقائيًا، والقاعدة بجانب الملف.
  • Docker: docker compose up -d app ثم افتح http://127.0.0.1:8000/.
  • مطوّر: pip install -r requirements.txt ثم python -m uvicorn main:app --reload ثم افتح http://127.0.0.1:8000/.

2. تسجيل الدخول واللغة وإدارة الحساب

  • أدخل اسم المستخدم وكلمة المرور ثم «تسجيل الدخول».
  • تبديل اللغة: زر 🌐 EN في شاشة الدخول أو الترويسة يبدّل عربي ⇄ English (RTL ⇄ LTR) ويحفظ اختيارك في المتصفح — القوائم والجداول والرسائل كلها تُترجم.
  • الوضع الداكن 🌙: زر 🌙 في الترويسة (وفي شاشة الدخول) يبدّل الوضع الفاتح/الداكن ويحفظ اختيارك في المتصفح — يُطبَّق فورًا على الشاشات والجداول والنماذج. وإذا لم تختر يدويًا يتبع النظام تفضيلك تلقائيًا عند أول زيارة prefers-color-scheme، واختيارك اليدوي يبقى محفوظًا بعد إعادة التحميل.
  • تغيير كلمة المرور: زر 🔑 في الترويسة ← أدخل الحالية الجديدة.
  • الجرس 🔔: يعرض عدد الإشعارات غير المقروءة (تذكير موعد، جاهزية تحليل، تنبيه مخزون) — انقر عليه لفتح صفحة الإشعارات.
  • البحث الفوري 🔍: اضغط Ctrl + K (أو انقر زر 🔍 في الترويسة) لفتح نافذة بحث واحدة تبحث في المرضى والأدوية والفواتير والمواعيد والوصفات دفعةً واحدة — اكتب حرفًا واحدًا على الأقل، تنقّل بالسهمين ↑ ↓، افتح النتيجة بـ Enter (تقفز إلى شاشتها)، وأغلق النافذة بـ Esc.
  • الحماية: بعد 5 محاولات دخول فاشلة يُقفل الدخول 15 دقيقة (429)، ويوجد حد منفصل لكل عنوان شبكة — لا تكرر التخمين.

3. لوحة التحكم والإحصائيات

  • بطاقات: عدد المرضى، الأطباء، مواعيد اليوم، الإيرادات، إشغال الأسرّة.
  • مخطط أعمدة للحالات وحالة النظام (القاعدة، التذكيرات، النسخ التلقائي).
  • للمسؤول: زر «تقرير PDF» شهري (?month=YYYY-MM) — الطبيب يحصل على تقرير مرضاه فقط.
  • صفحة مراقبة عامة دون تسجيل دخول: /monitor — أيقونات خضراء/حمراء تتحدث كل 15 ثانية.

4. المرضى

  • إضافة مريض: الاسم، تاريخ الميلاد، الجنس، الهاتف، البريد — الهوية الوطنية مميّزة، وحقلان اختياريان للتأمين (شركة التأمين + رقم الوثيقة).
  • البحث: بالاسم أو الهاتف أو الهوية الوطنية، مع فلتر فصيلة الدم.
  • الملف الشامل PDF: زر في صف المريض — بيانات + سجلات طبية + مواعيد + فواتير + مرفقات في ملف واحد.
  • الحذف للمدير فقط؛ التصدير/الاستيراد CSV من زر ⬆️⬇️ (يفتح عربيًا في Excel).

5. الأطباء والأقسام والأسرّة والموظفون

  • الأطباء: تخصص + ربط بقسم — بحث وفلاتر (قسم/توافر) وبطاقة إحصاءات أعلى الشاشة + ✏️ تعديل منبثقة و⛅ تبديل توافر سريع (للمدير أو الطبيب نفسه بحسابه) + 📈 تقرير أداء شهري لكل طبيب (مواعيد الشهر حسب الحالة ونسبة الإتمام والمرضى والسجلات) مع أزرار ⬇️ CSV و🖨️ PDF و🪪 بطاقة الترخيص، + 🗓️ نوبات عمل أسبوعية (سبت–جمعة، نوبتان في اليوم الواحد (صباحية ومسائية) بحفظ استبدال الأسبوع كاملًا مع رفض التداخل والتكرار ورفض الموعد خارج نوبات العمل) و📊 «أداء الشهر» تقرير مقارن مرتّب لجميع الأطباء — الحذف للمدير فقط مع رفض 409 لمن لديه سجلات طبية أو مواعيد (عُطِّل بدلًا من حذفه).
  • الأقسام: باطنية، جراحة، طوارئ… (إنشاء/حذف للمدير).
  • الأسرّة: حالات متاح/مشغول/صيانة مع إسناد المريض.
  • الموظفون: بيانات + الرأس الشهري (يُستخدم في الرواتب).

6. المواعيد والطابور والتقويم

  • حجز: مريض + طبيب + تاريخ ووقت — يُمنع حجز موعد متعارض مع التوفر.
  • الحالات: معلّمؤكد ← مكتمل / ملغي — أزرار «تأكيد / إتمام / إلغاء» في الجدول.
  • 🎫 الطابور: زر «تسجيل وصول» يعطي المريض رقمًا تسلسليًا لليوم (يمنع التكرار على الموعد الملغى/المكتمل) — بطاقة «في الخدمة الآن» تعرض الموعد الحالي.
  • 📅 التقويم: زر «🗓️ تقويم» — شبكة أسبوعية ملوّنة حسب الحالة مع تنقّل بين الشهور وعدّاد +N.
  • يُرسل تأكيد للمريض وتذكير قبل الموعد بـ24 ساعة (بريد/إشعار).

7. المختبر والأشعة

  • طلب تحليل/أشعة: مريض + اسم التحليل + السعر (اختياري).
  • الحالات: مسجّل ← قيد التنفيذ ← جاهزة ← مراجَعة — النتيجة إلزامية قبل «جاهزة»، وعند الجاهزية يُنشأ إشعار للجميع.
  • الطبيب يرى طلبات مرضاه فقط؛ تقارير PDF/CSV من شاشة التقارير.
  • 🖨️ ورقة النتيجة PDF: زر على كل طلب ينزّل ورقة النتيجة بالعربي أو الإنجليزي (تبعًا لغة الواجهة) — بنفس صلاحية عرض الطلب (طبيب غير مالك لا يراها) — مع فلتر حالة وبحثًا فوق جدول الطلبات.

8. الصيدلية والمخزون

  • 🛒 سلة الصرف: بحث بالاسم أو الرمز + مسح باركود يختار الدواء في السطر الأخير — سلة متعددة البنود تُصرف دفعة واحدة (all-or-nothing: إن فشل بند واحد لا يتغيّر أي شيء)، مع حقول الجرعة/التكرار/المدة/تعليمات تظهر في الإيصال.
  • ⛔ رفض المنتهي: أي دواء منتهي الصلاحية يُرفض الصرف عليه (400) مع رسالة واضحة، وبقائمه تظهر بحالة «منتهي الصلاحية».
  • ↩ الإرجاع: زر «إرجاع» على أي عملية صرف بسبب إلزامي — يعيد الكمية للمخزون ويقيَّد حركة «إرجاع»، ويخرج تلقائيًا من المبيعات والإيراد والمدينين وكشف الحساب (وسجل المبيعات CSV).
  • 🗑️ الإتلاف (للمدير): كمية تالفة تُخصم وتُسجَّل حركة «إتلاف» في دفتر الحركات وتظهر في تقرير CSV منفصل.
  • 📋 الوصفات الطبية: إنشاء وصفة (طبيب/مدير) ببنود وجرعات — حالتها PENDING ← PARTIAL ← DISPENSED (أو ملغاة)، والصرف منها ذرّي (كل البنود أو لا شيء) ويرتبط بكل عملية صرف — مع زر 🖨️ طباعة الوصفة PDF (عربي/إنجليزي) وفلتر حالة الوصفات أعلى الجدول.
  • ⏳ الوصفات المعلّقة: بطاقة أعلى شاشة الصيدلية تجمع وصفات PENDING لم تُصرف منذ أكثر من 24 ساعة (حدّها STALE_RX_HOURS) بأرقامها وعمرها بأزرار طباعة/صرف/إلغاء + إشعار «وصفة معلّقة» في صفحة الإشعارات يُنشأ مرة واحدة فقط لكل وصفة مهما تكررت الدورات، وزر «عرض المعلّقات» ينقلك لفلترها في الجدول.
  • 📊 الإحصاءات واقتراحات الطلب: بطاقات أعلى الصفحة (إيراد/محصّل/متبقي/وحدات/عمليات/تنبيهات) للفترة + قائمة «اقتراحات إعادة الطلب» بالمستهلَك اليومي والمتوسط وكمية الشراء المقترحة وزر «توريد المقترح» + زر «🛒 طلب CSV» لتصديرها للمشتريات.
  • المخزون: بطاقة ملخّص (قيمة/أصناف/منخفض/نافد/قارب الانتهاء) + دفتر حركات (رصيد افتتاحي، صرف، توريد، جرد، إتلاف، إرجاع) برصيد بعد الحركة.
  • التوريد والجرد والإتلاف للمدير فقط: توريد يزيد الكمية، وجرد يضبطها بالكمية الفعلية — كلاهما يقيَّد حركة موقّعة.
  • 🏷️ ملصقات الباركود PDF: زر «ملصق» بجانب كل دواء في صفَي الصيدلية والمخزون و«🏷️ ملصقات الكل» في شريطيهما — ملف med_labels.pdf بورقة A4 مقسّمة 3×7 ملصقًا يحمل كل واحد اسم الدواء ورمزه وسعره وبَركود Code39 أسفله (للمدير فقط).
  • تقارير الصيدلية: PDF المخزون (+ حركات الإتلاف/الإرجاع) · إحصاءات PDF/CSV لفترة · CSV المخزون/الصرف/الإتلاف-الإرجاع.

9. المبيعات والحسابات والرواتب

  • 🛒 المبيعات: سجل عمليات الصرف مع إجمالي/محصّل/متبقي — زر «تسديد» يفتح نافذة بمعاينة حيّة للمتبقي، و«سدّد الكل» يسوّي كل غير المسدد دفعة واحدة. حالات: UNPAID ← PARTIAL ← PAID.
  • 🧾 الحسابات: ملخص لكل طريقة دفع + فلاتر شهر/طريقة/حالة/مريض — كشف حساب المريض (مبيعات + فواتير + رصيد) بطباعة و تنزيل PDF بالعربي أو الإنجليزي + جدول «المدينون» مع زر كشف حساب لكل مدين + منحنى الإيراد يومي/شهري.
  • 💵 الرواتب (للمدير): قيد شهري (أساسي + بدلات − استقطاعات = صافي) + صرف + كشف PDF/CSV.
  • 🗂️ تبويبات المحاسبة السبعة: الشاشة صارت شاشة واحدة بسبع تبويبات — نظرة عامة · المبيعات · المدينون · الفواتير · الدفتر العام · التقارير · الرواتب — تُبدَّل فورًا دون إعادة بناء الشاشة، وروابط القائمة الجانبية (المبيعات/الحسابات/الرواتب/الفواتير) اختصارات إلى تبويبها مباشرة.
  • الإيصال 🧾 لكل عملية بيع — صفحة HTML جاهزة للطباعة.

11. المستخدمون والنسخ الاحتياطي

  • المستخدمون (للمدير): إنشاء حساب بصلاحية (مدير/طبيب/موظف استقبال)، تغيير الصلاحية، تفعيل/تعطيل — بحارس «آخر مدير نشط» لا يُعطَّل.
  • سجل التدقيق (للمدير): كل عملية تعديل مع المستخدم والمسار والحالة + تحليل استخدام وأخطاء ومحاولات دخول فاشلة.
  • النسخ الاحتياطي (للمدير): زر «إنشاء نسخة» + قائمة النسخ بزر تنزيل ♻️ استعادة — الاستعادة تصنع نسخة أمان أولًا وتفحص سلامة الملف قبل الاستبدال.
  • فحص السلامة (للمدير): زر «🩺 فحص السلامة» يقرأ أحدث النسخ بـquick_check (أو فحص عميق deep=1) دون مساس بالملفات — أي نسخة تالفة تظهر برسالة الخطأ.
  • تنظيف حسب السياسة: زر «🧹 تنظيف النسخ» يبقي آخر 7 نسخ من كل نوع (hospital_*.db اليدوي وauto_*.db التلقائي) ويحذف الزائد فورًا — مع شريط حالة (العدد والحجم والأقدم والأحدث ومساحة القرص).
  • نسخ تلقائي يومي: آخر 7 نسخ في backups/auto_*.db (SQLite) — وعلى PostgreSQL يُنتج حاوية backup نسخة pg_dump مجدولة يوميًا.

12. التطبيق المكتبي (PWA) واستكشاف الأخطاء

PWA — تثبيت واستخدام دون اتصال

  • من المتصفح: «تثبيت التطبيق» / «إضافة إلى الشاشة الرئيسية» — الأيقونة والقشرة جاهزة.
  • بعد أول زيارة: تُخزَّن الواجهة الأساسية فيبقى النظام قابلًا للفتح دون إنترنت، وتُخزَّن شاشة الطابور لعرض آخر حالة.
  • الشبكة أولًا دائمًا: لا يعرض المتصفح واجهة قديمة عند التحديث.
